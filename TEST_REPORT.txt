Root cause and resolution:

- the original repository and Render service were disconnected
- the original SQLite database used an ephemeral free-service filesystem
- safety and governance decisions discussed in chat were not permanently encoded
  or regression-tested
- FastAPI startup, OpenAPI, authentication, PostgreSQL persistence, sanitized
  errors, retention and request limits were normalized and tested
- all 12 Safety Gate flags are mandatory; missing data does not mean normal
- governance moved from a single boolean to an expiring, multi-control fail-closed gate
- deployment now waits for GitHub checks before release

Current limitations and release boundary:

- the free PostgreSQL database expires on 2026-09-26 and has no backups or PITR
- one global API key does not provide individual identity, RBAC or per-user revocation
- GitHub branch protection and required-review enforcement are not yet confirmed
- the 50 automated cases still require signed independent human clinical review
- technical, clinical, privacy and legal owners remain to be formally appointed
- legal basis, formal RIPD approval, supplier review and SaMD analysis are pending
- the GPT Action privacy-policy URL is not configured; the GPT must remain private
  until an approved policy is published and linked
- identifier detection is defense in depth, not proof of anonymization
- the evidence endpoint remains a metadata-only placeholder; no medical RAG or
  vector store is connected
- the free web service can cold-start after inactivity
- Docker is hardened for non-root execution, but the image was not built locally
  because Docker is not installed on this machine
